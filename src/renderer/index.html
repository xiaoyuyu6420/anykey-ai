① 按键盘上的「AI 切换」键进入/退出 AI 模式（F 行白灯亮） → ② 在下面对每个键配置动作 → ③ 按键即触发。

两种模式各配各的：比如普通模式 F10 留给输入法语音，AI 模式 F10 绑开麦+勾「保留原按键功能」。tab 上的数字 = 该模式已自定义的键数（初次两份相同是旧配置复制，改过哪份哪份就独立了）。键盘实际处于哪个模式看右侧徽章。直接按键盘上的键，对应行会闪烁高亮。双击行名称可改备注名。

怎么接入识别软件（首次配置）

装虚拟声卡：Windows 用 VB-Cable（vb-audio.com/Cable），macOS 用 BlackHole（brew install blackhole-2ch）。然后勾上面的「启用桥接」，播放设备选 CABLE Input / BlackHole 2ch。最后把系统默认输入设备设成 CABLE Output / BlackHole 2ch——任意软件（微信输入法等）就能把键盘麦克风当麦克风用了。
