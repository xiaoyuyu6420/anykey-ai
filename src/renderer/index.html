前台应用自动切档

按前台进程名（exe 名，不区分大小写）自动切换键位档；手动切档后，前台应用不变期间不会被自动接管。仅 Windows 支持自动检测，mac 请用托盘或按键手动切档。

怎么接入识别软件（首次配置）

装虚拟声卡：Windows 用 VB-Cable（vb-audio.com/Cable），macOS 用 BlackHole（brew install blackhole-2ch）。然后勾上面的「启用桥接」，播放设备选 CABLE Input / BlackHole 2ch。最后把系统默认输入设备设成 CABLE Output / BlackHole 2ch——任意软件（微信输入法等）就能把键盘麦克风当麦克风用了。
